# Video script

A 6 to 8 minute walk through the working system, recorded against the Compose stack. It follows Flow A (does a change help?) and then one investigation (why did a run pass or fail?). Times are targets; the voice-over is a guide, not a script to read word for word.

## Before you record

- Start the stack and let it settle: `docker compose up -d --build`, then open http://localhost:8080.
- For the real-model scenes, connect Nous Portal on the System page (or have `hermes proxy start --provider nous` running with `NOUS_HOST_PROXY` set), and set the judge to the real model in `.env` (`JUDGE_PROVIDER=nous`, `JUDGE_MODEL=openai/gpt-6.1-sol`).
- Have the official experiment, `invoices-v1-skill-official`, already completed, and one sample experiment run on the mock. A real experiment takes about 14 minutes, so record its launch, then cut to the finished one.
- Use a browser window about 1440 px wide, the dark theme, and close other tabs. Zoom to 110% if the text is small on the recording.

## Notes for the edit

- Keep the cursor still while you talk over a screen; move it only to point.
- Cut every wait longer than about 3 seconds.
- If a figure on screen differs from the voice-over (for example a later re-run), say the figure on screen.
